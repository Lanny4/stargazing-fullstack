# Лабораторна робота №4. Робота з даними користувача

## Мета
Опрацювати введення даних через форми, localStorage, серверні сесії, валідацію та основи безпеки.

## Що робить програма
1. React приймає ім’я, телефон, процедуру, дату, час і необов’язковий коментар.
2. `POST /api/appointments` приймає JSON; Express повторно перевіряє всі дані.
3. PostgreSQL зберігає демонстраційну заявку й генерує довідковий номер `SG-...`.
4. `express-session` із `connect-pg-simple` тримає сесію в PostgreSQL, у браузері — лише HttpOnly-cookie.
5. Список `GET /api/appointments/mine` повертає заявки поточної сесії без телефонів та ПІБ.
6. `localStorage['stargazing.category']` зберігає **лише обрану категорію каталогу**, не приватні дані.

## Приклади перевірок
- Надіслати правильну тестову форму → 201 і довідковий номер.
- Ввести номер `123` → повідомлення про невалідний номер.
- Вказати минулу дату → помилка на сервері (422), навіть якщо обійти HTML-валидацію в Postman.
- Перезавантажити сайт → фільтр категорії зберігається через localStorage.
- DevTools → Application → Local Storage → `stargazing.category`.
- DevTools → Application → Cookies → `stargazing.sid` із прапорцем **HttpOnly**.

## Захист
- Helmet для HTTP-заголовків (CSP в цьому навчальному шаблоні вимкнено).
- Ліміт JSON 20 KB; обмеження частоти запитів до форми й AI.
- Серверна перевірка полів, параметризовані SQL-запити, перевірка Origin для POST браузера.
- Cookie HttpOnly, SameSite=Lax; Secure при production HTTPS.
- `.env` у `.gitignore`; API-ключі ніколи не вставляються в клієнтський код.

**Важливо:** цей демонстраційний приклад не надає повноцінної автентифікації, не готовий до роботи з реальними даними пацієнтів і не замінює медичної інформаційної системи.

## Скриншоти
1. Форма на сайті до заповнення.
2. Повідомлення про успішно збережену демозаявку (із вигаданими даними).
3. 422 у Postman для неправильного номера чи дати.
4. DevTools Local Storage — обрана категорія.
5. DevTools Cookies — HttpOnly, SameSite.
6. Код `validateAppointment` та SQL `INSERT`.

## Висновок для уточнення після запуску
