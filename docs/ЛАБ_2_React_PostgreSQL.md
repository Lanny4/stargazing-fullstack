# Лабораторна робота №2. Розробка інтерактивного клієнтського інтерфейсу

## Мета
Ознайомитися з React, побудувати клієнтський інтерфейс із динамічним відображенням даних і використати PostgreSQL через серверний API.

## Теорія коротко
- **React** — бібліотека для інтерфейсів із компонентів; зміни стану (`useState`) спричиняють повторне відображення потрібної частини інтерфейсу.
- **Vite** — інструмент локальної розробки й збірки.
- **JSX** — синтаксис для опису компонентів.
- **`useEffect`** — виконує побічні ефекти, зокрема запит `fetch` при відкритті сторінки.
- **PostgreSQL** — реляційна база з таблицями, типами даних і SQL-запитами.
- **Динамічний рендеринг** — React створює картки за даними з API, а не за окремо написаними HTML-блоками.

## Виконання
1. Встановити Node.js 22.12+ і PostgreSQL на Windows; відкрити `Stargazing_Labs_2-6` у VS Code.
2. У pgAdmin створити `stargazing_user` і базу `stargazing` за README; налаштувати `server/.env`.
3. У терміналі VS Code виконати `npm install`, `npm run db:setup`, `npm run dev`.
4. Відкрити `http://localhost:5173/`. React відображає каталог із шести послуг.
5. Натиснути «Догляд», «Обличчя», «Консультації»: картки фільтруються без перезавантаження.
6. Відкрити `http://localhost:4000/api/services`: відповідь сервера — JSON із послугами.
7. У pgAdmin виконати `SELECT id, title, category, price_uah FROM services ORDER BY position;`.

## Де саме код
`client/src/main.jsx`: компонент `App`, `useState`, `useEffect`, `services.map`, `visible.map`, `setCategory`; `server/db/schema.sql` і `server/db/seed.sql`: структура і початкові значення БД.

## Скриншоти
1. VS Code: React `useEffect`/`fetch('/api/services')` — показати отримання даних.
2. Сторінка Stargazing із каталогом із бази — результат.
3. Натиснута категорія і менше карток — динамічна фільтрація.
4. pgAdmin: таблиця `services` з шістьма рядками — дані в PostgreSQL.
5. Браузер: JSON `GET /api/services` — шлях від БД до клієнта.
