# Лабораторна робота №6. Інтеграція з інтелектуальними сервісами

## Мета
Навчитися викликати готовий AI API з вебзастосунку і відображати відповідь користувачеві.

## Реалізація
- React-компонент у `client/src/main.jsx` містить форму запитання і чат-повідомлення.
- `POST /api/ai/consult` приймає запитання, перевіряє довжину і викликає OpenAI Responses API з Express.
- На сервері використовуються `OPENAI_API_KEY` і `OPENAI_MODEL`, задані в ENV; ключ не повертається в браузер.
- Повертається JSON `{ "answer": "..." }`, який React додає в чат.
- Інструкція AI обмежує відповіді загальною інформацією про догляд, без діагностики чи персональних медичних призначень.

## Кроки
1. Отримати власний API-ключ на платформі OpenAI; попередньо перевірити доступність моделі та можливу оплату API.
2. У `server/.env` вказати `OPENAI_API_KEY=...` і `OPENAI_MODEL=gpt-5-mini` (або доступну модель).
3. Перезапустити `npm run dev`.
4. Відкрити секцію **AI-помічник** на `http://localhost:5173/`.
5. Написати «Для чого потрібен SPF?» і надіслати.
6. Перевірити отриману відповідь, також за бажанням — Postman запит №7.
7. Видалити ключ зі скриншотів і не завантажувати `.env` у GitHub.

## Помилки
- 422 — питання коротше трьох або довше 500 символів.
- 503 — API-ключ відсутній (очікувано до налаштування).
- 502 — проблема підключення до OpenAI, тарифу, моделі або іншої помилки зовнішнього сервісу.

## Скриншоти
1. JSX-код чату та обробник події.
2. Серверний endpoint зі зверненням до Responses API (секрети не видно).
3. Чат до запитання.
4. Фактична відповідь AI після запиту.
5. Postman або DevTools Network для `POST /api/ai/consult` та HTTP 200.

**Статус до власного ключа:** інтеграцію закодовано, але зовнішній AI-виклик не протестовано; це потрібно чесно відобразити в звіті.
